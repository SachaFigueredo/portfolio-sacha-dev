| Next.js | 16.2.4 (App Router, Turbopack) |

| Framer Motion | 12 |

## Secciones

- **Inicio** — Hero con animaciones y CTAs
- **Sobre Mí** — Perfil profesional y enfoque en resultados
- **Tecnologías** — Grid del stack técnico
- **Proyectos** — Tarjetas con proyectos reales
- **Servicios** — Lo que puedo hacer por clientes
- **Contacto** — Formulario con envío real de emails + redes sociales

## Arrancar en local

```bash
npm install
npm run dev
# → http://localhost:3000
```

## Build

```bash
npm run build     # producción
npm run lint      # ESLint flat config
```

## Variables de entorno

Creá un archivo `.env.local` en la raíz:

```env
RESEND_API_KEY=re_tu_key_acá
```

Obtené una key gratis en [resend.com](https://resend.com).

## Deploy

Ideal para **Vercel** (creado por los mismos de Next.js). Conectá tu repo y deploy automático.
